# \# 📰 Fake News Detection System

# 

# NLP course project — Capital University (Faculty of Computing \& Artificial Intelligence), Spring 2025-2026.

# 

# Classifies news articles as \*\*Fake\*\* or \*\*Real\*\*, explains the prediction with key triggering words, and compares a Logistic Regression baseline against an LSTM model with GloVe embeddings.

# 

# \---

# 

# \## Project structure

# 

# ```

# Fake-News-Project/

# │   README.md

# │   requirements.txt

# │   streamlit\_app.py

# │

# ├── data/

# │   ├── glove/          ← GloVe vectors (downloaded automatically by notebook 3)

# │   ├── processed/      ← clean\_data.csv (generated by notebook 2)

# │   └── raw/

# │           Fake.csv

# │           True.csv

# │

# ├── notebooks/

# │       01\_exploration.ipynb    ← EDA, class balance, top words, length stats

# │       03\_modeling.ipynb       ← Training, evaluation, model comparison

# │

# ├── outputs/

# │   ├── models/         ← Saved model artefacts (.pkl / .pth)

# │   └── results/        ← Metrics JSON + chart PNGs

# ```

# \## Running the notebooks

# 

# Run the notebooks \*\*in order\*\* from the `notebooks/` folder:

# 

# ```

# 01\_exploration.ipynb   → EDA charts saved to outputs/results/

# 02\_preprocessing.ipynb → Cleaned CSV saved to data/processed/

# ```

# > \*\*GloVe embeddings\*\* — notebook 3 downloads `glove.6B.zip` (\~822 MB) automatically on first run and caches it in `data/glove/`. Subsequent runs skip the download.

# \## Models

# 

# | Model | Features | Accuracy | Precision | Recall | F1 |

# |-------|----------|:--------:|:---------:|:------:|:--:|

# | Logistic Regression | TF-IDF (50k, bigrams) | 99.1 % | 99.0 % | 99.1 % | 99.0 % |

# \## Prediction output format

# 

# ```

# Prediction: FAKE — Reason: "breaking", "shocking", "exposed"

# Prediction: REAL — Reason: "according to", "study", "reported"

# ```

# 

# The dashboard also shows:

# \- Confidence score for each model

# \- Key word influence chart (Logistic Regression)

# \- Signed token saliency chart (LSTM) — green = pushes toward REAL, red = pushes toward FAKE

# \- Linguistic pattern check (sensationalist vs factual signals)

# \## Preprocessing pipeline

# 

# Applied identically during training and inference:

# 

# 1\. Lowercase

# 2\. Remove source tags (`reuters`, `21st century wire`)

# 3\. Remove digits

# 4\. Remove punctuation

# 5\. Remove NLTK English stopwords

# 6\. Remove single-character tokens
