# Fake News Detection

## Objective
Classify news into Fake or Real + explain predictions.

## Models
- Logistic Regression (TF-IDF)
- LSTM (PyTorch)

## Features
- Preprocessing
- Explainability
- Pattern detection
- Statistics

## Run
pip install -r requirements.txt
python main.py

## Output
- Accuracy / Precision / Recall / F1
- Confusion Matrix
- Explanation
- Patterns
