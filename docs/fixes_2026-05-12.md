## `02_LG_TF-IDF.ipynb`

### Issue #1 — Fixed `explain` function (critical)
**Cell:** 8 (renumbered from 7 after CV cell insert)

```python
# Before — returned any input word that existed in the full 5000-word vocab
def explain(text):
    vec = tfidf.transform([text])
    pred = model.predict(vec)[0]
    words = text.split()
    important_words = [w for w in words if w in word_score]
    label = "Fake" if pred == 1 else "Real"
    return label, important_words

# After — returns top-N words by |TF-IDF_value × model_coefficient|
def explain(text, top_n=10):
    vec = tfidf.transform([text])
    pred = model.predict(vec)[0]
    label = "Fake" if pred == 1 else "Real"

    feature_indices = vec.nonzero()[1]
    contributions = [
        (features[i], float(weights[i] * vec[0, i]))
        for i in feature_indices
    ]
    contributions.sort(key=lambda x: abs(x[1]), reverse=True)
    important_words = [word for word, _ in contributions[:top_n]]
    return label, important_words
```

**Before:** Nearly every common input word passed the filter (the entire vocab was in `word_score`), plus case mismatch (`"Breaking"` ≠ `"breaking"`).  
**After:** Only words actually present in the TF-IDF vector are considered; ranked by their signed contribution to the prediction score.

### Issue #2 — Fixed `explain_text` function (critical)
**Cell:** 17

```python
# Before — returned every input word that existed in the 20k tokenizer vocabulary
def explain_text(text):
    ...
    important_words = [w for w in words if w in tokenizer.word_index]
    return label, important_words

# After — perturbation: masks each word and measures probability drop
def explain_text(text, top_n=10):
    words = text.lower().split()

    def predict_prob(word_list):
        seq = tokenizer.texts_to_sequences([" ".join(word_list)])
        padded = pad_sequences(seq, maxlen=300)
        return model.predict(padded, verbose=0)[0][0]

    base_prob = predict_prob(words)
    scores = []
    for i, word in enumerate(words):
        masked = words[:i] + ["<OOV>"] + words[i+1:]
        delta = base_prob - predict_prob(masked)
        scores.append((word, delta))

    scores.sort(key=lambda x: abs(x[1]), reverse=True)
    label = "Fake" if base_prob > 0.5 else "Real"
    important_words = [w for w, _ in scores[:top_n]]
    return label, important_words
```

**Before:** Returned almost the entire input (most words exist in the 20k vocab) — not informative.  
**After:** Each word is blanked out with `<OOV>` one at a time; words that cause the largest probability shift when removed are ranked highest. Results reflect genuine LSTM decision drivers.
